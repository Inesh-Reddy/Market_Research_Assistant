# Shared Contracts (source of truth)
FastAPI's OpenAPI schema is the contract source of truth: run the backend, open http://localhost:8000/openapi.json, and generate TypeScript types with `npx openapi-typescript http://localhost:8000/openapi.json -o apps/frontend/src/types/openapi.ts`. Hand-written frontend types in `apps/frontend/src/types/index.ts` mirror the Pydantic schemas in `apps/backend/app/schemas/` (chat, agent, execution, events) and must be updated together. No duplicated ad-hoc shapes: event payloads follow `ExecutionEvent` (event_id, execution_id, conversation_id, event_type, agent_name, timestamp, duration_ms, payload).
